# 📝 Bewerbungs-Anschreiben Template

**HINWEIS:** Dies ist eine VORLAGE. Für jede Bewerbung wird dieses Template mit folgenden Daten gefüllt:
- `[FIRMA]` → Arbeitgeber (z.B. "Stadtverwaltung Montabaur")
- `[POSITION]` → Jobtitel (z.B. "Sachbearbeiterin Büro-Management")
- `[KONTAKT]` → Name der Kontaktperson (z.B. "Herr Schmidt")
- `[ABTEILUNG]` → Zuständige Abteilung (z.B. "Abteilung Verwaltung")
- `[MATCH-PUNKTE]` → Qualifikations-Abgleich (generiert basierend auf Jobanforderungen)
