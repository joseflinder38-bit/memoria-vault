# 📄 LEBENSLAUF TEMPLATE – ÜBERSICHT

Willkommen! Diese Ordner enthält alles, was du brauchst, um professionelle Lebensläufe zu erstellen und als PDF zu exportieren.

---

## 📁 DATEIEN IN DIESEM ORDNER

### 1️⃣ **Lebenslauf-Template-Markdown.md** ⭐ START HIER
- **Format:** Markdown (bearbeitbar)
- **Nutzung:** 
  - Öffne diese Datei in Obsidian
  - Fülle alle Platzhalter `[HIER EINTRAGEN]` aus
  - Speichere unter neuem Namen (z.B. `Lebenslauf_DeinName_2026.md`)
- **Vorteil:** Einfach zu bearbeiten, direkt in Obsidian

### 2️⃣ **Lebenslauf-Template-HTML.html**
- **Format:** HTML (professionelle Formatierung)
- **Nutzung:**
  - Kopiere den Inhalt aus der Markdown-Version
  - Ersetze die `[PLATZHALTER]` in dieser HTML-Datei
  - Öffne die Datei in Chrome
  - Exportiere als PDF (siehe Anleitung unten)
- **Vorteil:** Sieht aus wie ein echtes Dokument, druckfreundlich

### 3️⃣ **HTML-zu-PDF-Anleitung.md** 📖
- **Inhalt:** Schritt-für-Schritt Anleitung
- **Themen:**
  - Wie man HTML in Chrome öffnet
  - Wie man als PDF exportiert
  - Tipps für die beste Qualität
  - Häufige Fehler & Lösungen

## 🚀 SCHNELLEINSTIEG – 5 SCHRITTE

### **Schritt 1: Template kopieren**
1. Öffne `Lebenslauf-Template-Markdown.md` in Obsidian
2. Kopiere den kompletten Inhalt (Strg + A → Strg + C)

### **Schritt 2: Neue Datei erstellen**
1. Erstelle eine neue Datei in `02 Areas/Persönliche Daten/`
2. Name: `Lebenslauf_DeinName_2026.md`
3. Füge den kopiertem Inhalt ein

### **Schritt 3: Ausfüllen**
1. Ersetze alle `[HIER EINTRAGEN]` Platzhalter
2. Nutze `[[02 Areas/Persönliche Daten/Stammdaten-VERIFIZIERT]]` als Datenquelle
3. Speichern (Strg + S)

### **Schritt 4: HTML erstellen**
1. Kopiere den Inhalt aus deiner neuen Lebenslauf-Datei
2. Öffne `Lebenslauf-Template-HTML.html` in VS Code oder Editor
3. Ersetze die `[PLATZHALTER]` im HTML-Body
4. Speichern

### **Schritt 5: Als PDF exportieren**
1. Öffne die HTML-Datei in Chrome: 
   ```
   Rechtsklick auf .html → "Öffnen mit → Google Chrome"
   ```
   oder
   ```
   Strg + O im Chrome → Datei wählen
   ```
2. Drücke **Strg + P** (oder Drucken im Menü)
3. Wähle: **"Als PDF speichern"**
4. Klick: **"Speichern"** ✅

Fertig! 🎉

## 💡 TIPPS & BEST PRACTICES

### **Beim Ausfüllen:**
- ✅ Nutze echte Daten aus `Stammdaten-VERIFIZIERT.md`
- ✅ Halte Zertifikate aktuell
- ✅ Ergänze Telefonnummer (KRITISCH!)
- ✅ Addiere Berufliche Referenzen (mindestens 2–3)

### **Beim Exportieren als PDF:**
- ✅ Stelle sicher, dass Chrome vollständig geöffnet ist
- ✅ Nutze "Rand: Minimal" bei den Druckeinstellungen
- ✅ Überprüfe die Vorschau vor dem Speichern
- ✅ Speichere mit aussagekräftigem Namen (z.B. `Lebenslauf_Josef_Linder_2026-07.pdf`)

### **Häufige Fehler:**
- ❌ **Falsches Format:** HTML muss in Chrome sein, nicht in Word
- ❌ **Verlust der Formatierung:** Kopiere nicht in Word — exportiere direkt als PDF
- ❌ **Fehlende Daten:** Nutze `Stammdaten-VERIFIZIERT.md` als Single Source of Truth

## 📋 ANLEITUNG FÜR ZUKÜNFTIGE PROJEKTE

Diese Anleitung gilt für ALLE zukünftigen Lebensläufe (dein eigener oder fremde):

1. **Vorlage wählen:** `Lebenslauf-Template-Markdown.md` oder `.html`
2. **Daten sammeln:** Aus verifizierten Quellen (Zeugnisse, Zertifikate, Stammdaten)
3. **Ausfüllen:** Alle Platzhalter ersetzen
4. **HTML-Version erstellen:** Falls professionell formatiert nötig
5. **In Chrome öffnen:** Via Rechtsklick oder Strg + O

7. **Speichern:** Mit Datum (z.B. `..._2026-07.pdf`)

## ❓ FAQ

**F: Kann ich das Template direkt in Word bearbeiten?**  
A: Nein. Nutze die Markdown-Version in Obsidian oder die HTML-Version in einem Editor (VS Code). Exportiere dann als PDF, nicht als Word-Dokument.

**F: Wie ändere ich die Farben/Formatierung?**  
A: In der HTML-Datei findest du den `<style>` Bereich. Ändere die Farben (z.B. `#1a5490` → deine Wunschfarbe).

**F: Warum nicht direkt Word verwenden?**  
A: HTML + PDF bietet bessere Kontrolle über die Formatierung und sieht auf allen Geräten gleich aus.

**F: Kann ich mehrere Lebensläufe haben?**  
A: Ja! Erstelle separate Markdown-Dateien (z.B. `Lebenslauf_Josef_Linder_2026-07.md`, `Lebenslauf_Josef_Linder_English.md`).
