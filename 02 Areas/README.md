# 🎯 02 Areas – Anleitung

Deine **laufenden Verantwortungen** ohne Enddatum. Nicht Projekte (mit Endziel), sondern **Lebensbereiche**.

## 🎯 Zweck

Areas sind:
- **Langfristig** (kein Enddatum)
- **Wiederkehrend** (laufen immer weiter)
- **Verantwortung** (DU musst sie managen)

**Beispiele:**
- 💼 Beruf (Jobsuche, Karriere-Entwicklung)
- 🧪 Gefahrstoffe Wissen (Fortbildung, Wissensmanagement)
- 💰 Finanzen (Sparen, Investitionen, Freelance)

## 📌 REGELN

**DO:**
- ✅ Lange Perspektive (Monate/Jahre)
- ✅ Monatlich überprüfen
- ✅ Mit Projekten verlinken
- ✅ In Daily Notes reflektieren

**DON'T:**
- ❌ Wie ein Project mit Enddatum behandeln
- ❌ Zu viele Areas (max. 5-7)
- ❌ Vergessene/tote Areas behalten
- ❌ Projekt-Details hier ablegen (→ 01 Projects/)

## 🎯 UNTERSCHIED: AREA vs. PROJECT

| Aspekt | Area | Project |
|--------|------|---------|
| **Enddatum** | Nein – läuft weiter | Ja – hat Ziel-Enddatum |
| **Umfang** | Breit (ganzer Lebensbereich) | Spitz (spezifisches Ziel) |
| **Beispiel** | "Karriere-Entwicklung" | "Bewerbung bei Firma XY" |
| | "Gefahrstoff-Fachgebiet" | "Gefahrstoffkataster für Kunde Z" |
| | "Finanzen verwalten" | "Ersparnisse €5.000 aufbauen" |
