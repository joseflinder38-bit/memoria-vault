## 📄 LEBENSLAUF

### "Überprüfe & optimiere Lebenslauf"
```
Überprüfe diesen Lebenslauf auf:
- Grammatik & Orthographie
- Unklarheiten
- Professionelle Sprache
- Logische Struktur
- Zu lange Sätze

Gib mir konkrete Verbesserungen:

[LEBENSLAUF HIER]
```

### "Anpassen für Firma XY"
```
Mein Lebenslauf:
[LEBENSLAUF]

Ich bewerbe mich bei: [FIRMA + POSITION]

Welche Skills sollte ich stärker hervorheben?
Welche Erfahrungen sind am relevantesten?
Wie würdest du die Reihenfolge ändern?
```

## 📝 BEWERBUNG SCHREIBEN

### "Anschreiben generieren"
```
Generiere mir ein professionelles Anschreiben:

Firma: [NAME]
Position: [TITEL]
Deine Stärken: [LISTE]
Besonderheiten: [Z.B. Gefahrstoff-Expertise]
Länge: 3-4 Absätze

Tone: Professionell, selbstbewusst, freundlich
Sprache: Deutsch
Format: Markdown

Mein Lebenslauf-Auszug:
[RELEVANTE DATEN]
```

### "Bewerbungs-Strategie"
```
Ich bewerbe mich als [POSITION] bei [FIRMA].

Erstelle einen Plan:
1. Undercover-Recherche (was sollte ich über die Firma wissen?)
2. Anschreiben-Fokus (welche Skills matchen?)
3. Vorbereitung Interview (3 Fragen, die sie stellen könnten)
4. Nachbereitung (Follow-up Message)

Meine Qualifikationen:
[KURZ BESCHREIBEN]
```

## 📊 MARKTDATEN & FINANZEN

### "Aktuelle Marktdaten erfassen"
```
Sammle aktuelle Marktdaten für heute:

Gib mir folgende Infos im Markdown-Format:
- DAX 40 (Indexpunkte, Änderung %)
- S&P 500 (Indexpunkte, Änderung %)
- MSCI World (Indexpunkte, Änderung %)
- Gold (€/Gramm)
- Silber (€/Gramm)
- Bitcoin (€)
- Ethereum (€)

Format als Tabelle:
| Instrument | Wert | Änderung % |

Quelle-Hinweis: Quelle: [Aktuelle Marktquellen]
```

### "Finanz-Analyse"
```
Analysiere meine Finanzen:

Meine Daten:
[EINNAHMEN/AUSGABEN TABELLE]

Erstelle für mich:
1. Zusammenfassung (monatlich / jährlich)
2. Top 5 Ausgabe-Kategorien
3. Trends (steigend/fallend?)
4. Sparquote
5. Empfehlungen zur Optimierung

Format: Markdown mit Tabellen
```

## ⚗️ GEFAHRSTOFFE

### "Gefahrstoff-Datenblatt"
```
Recherchiere Informationen zu: [STOFF-NAME]

Gib mir:
- Chemische Formel
- Gefahrenklasse (GHS)
- Signalwort
- H-Sätze (Gefahrenhinweise)
- P-Sätze (Sicherheitshinweise)
- Erste-Hilfe-Maßnahmen:
  * Nach Hautkontakt
  * Nach Augenkontakt
  * Nach Inhalation
  * Nach Verschlucken
- Lagerung (Bedingungen)
- Transport (Vorschriften)

Format: Strukturiertes Markdown
```

### "Betriebsanweisung anpassen"
```
Ich muss eine Betriebsanweisung anpassen.

Original-Vorlage:
[BA-TEXT]

Anpassungen für:
- Tätigkeit: [BESCHREIBUNG]
- Gefahrstoffe: [LISTE]
- Personen: [Z.B. Anfänger, Profis]
- Besonderheiten: [SPEZIALFALL]

Erstelle eine angepasste Version:
- Kürzer und präziser
- Verständlich für Anfänger
- Mit konkreten Beispielen
- Mit Checkliste am Ende
```

## 📋 NOTIZEN & DOKUMENTATION

### "Notizen strukturieren"
```
Strukturiere diese Notizen:

[ROHE NOTIZEN]

Erstelle:
1. Zusammenfassung (1-2 Sätze)
2. Wichtigste Punkte (Bullets)
3. Offene Fragen
4. Nächste Schritte
5. Verwandte Themen

Format: Markdown mit Überschriften
```

### "To-Do Liste aus Notizen"
```
Erstelle eine Checkliste aus diesen Notizen:

[NOTIZEN]

Format:
- [ ] Aufgabe 1 (Priorität: Hoch)
- [ ] Aufgabe 2 (Priorität: Mittel)
- [ ] Aufgabe 3 (Priorität: Niedrig)

Mit Deadline-Vorschlägen.
```

## 🎯 BRAINSTORMING & PLANUNG

### "Geschäftsidee bewerten"
```
Ich überlege: [GEFAHRSTOFF-BERATUNGS-IDEE]

Bewerte:
1. Marktpotential
2. Meine Qualifikationen (passen?)
3. Konkurrenz
4. Geschäftsmodell-Optionen:
   a) Vollzeitjob
   b) Freelance neben dem Job
   c) Startup gründen
5. Nächste Schritte zum Starten

Constraints:
- Budget: Gering
- Zeit: 10-20h/Woche möglich
- Skill: Gefahrstoffe + Office Management

Gib konkrete Handlungsschritte für nächste 30 Tage.
```

Erstelle mir einen Wochenplan:

- [PRIORITÄT 2]

Verfügbare Zeit:

Montag

## 🔍 RECHERCHE & ANALYSE

### "Firma recherchieren für Bewerbung"
```
Ich möchte mich bewerben bei: [FIRMA-NAME]

Recherchiere:
1. Unternehmenstypus (GmbH, AG, etc.)
2. Mitarbeiterzahl
3. Kerngeschäft
4. Besonderheiten (Awards, Auszeichnungen?)
5. Unternehmenskultur (soweit bekannt)
6. Abteilungsverantwortliche für [POSITION]
7. Aktuelle Projekte/Nachrichten
8. Bewerbungs-Anforderungen (typisch)

Format: Strukturiert, gut für Vorbereitung
```

### "Industrie-Trends"
```
Was sind aktuelle Trends in:
[GEFAHRSTOFF-INDUSTRIE / HAZMAT]

Gib mir:
1. Top 3 Trends 2026
2. Neue Regelungen (REACH, GHS Update, etc.)
3. Markt-Chancen für Berater
4. Typische Kundenbedürfnisse
5. Konkurrenz-Überblick

Format: Actionable Insights (nicht nur Info!)
```

## ✅ TIPPS FÜR BESSERE PROMPTS

### Golden Rules:
```
1. SEI SPEZIFISCH
   ❌ "Überprüfe meinen Lebenslauf"
   ✅ "Überprüfe meinen Lebenslauf auf Grammatik, 
       Klarheit und professionelle Sprache"

2. GIB KONTEXT
   ❌ "Schreib ein Anschreiben"
   ✅ "Schreib ein Anschreiben für [FIRMA] 
       bei Position [TITEL] basierend auf 
       meinem Hintergrund [SKILLS]"

3. DEFINIERE FORMAT
   ❌ "Fass zusammen"
   ✅ "Erstelle 3 Bullet Points + 1 Aktionsplan"

4. ITERIERE
   - 1. Prompt: Erste Version
   - 2. Prompt: "Kürzer & prägnanter"
   - 3. Prompt: "Mehr Fokus auf [ASPEKT]"
```
