## 🎯 Quick Start (3 Minuten)

### Setup (einmalig):
```
1. Obsidian öffnen
2. Einstellungen → "Files & Links"
3. "Vault location" → "iCloud Drive"
4. Vault wird geladen ✅

5. Safari/Chrome öffnen
6. https://copilot.microsoft.com
7. Login mit Microsoft-Account
8. Bookmark speichern! 🔖
```

### Tägliche Nutzung:
```
1. Obsidian öffnen → Notizen lesen/schreiben
2. Für Code/AI-Aufgaben → Copilot Tab öffnen
3. Copy-Paste deine Inhalte
4. Copilot macht Verbesserungen
5. Ergebnisse zurück in Obsidian
```

## 📱 iPad-Tipps & Tricks

### **Effizienter arbeiten:**
- 📌 Copilot-Tab im Browser bookmarken
- 🔄 Split-Screen: Obsidian + Safari
- ⌨️ iPad-Tastatur nutzen (schneller!)
- 📋 Copy-Paste-Verlauf nutzen (lange drücken)

### **iCloud Sync optimieren:**
- Einstellungen → iCloud → Drive → Immer verfügbar
- Obsidian → Settings → "Sync" auf Auto

### **Copilot im Browser:**
- Bing Copilot (free version)
- Copilot Pro (€20/Monat, wenn mehr Anfragen nötig)

## 🔄 Workflow-Beispiel (Tag im Leben)

```

```

→ 45 Minuten

### **Mittags (13:00):**
```
1. Notizen zur Gefahrstoff-Recherche machen
2. Copilot fragen: "Neue Gefahrstoffe-Trends?"

→ 30 Minuten
```

### **Abends (18:00):**
```
1. Finanzdaten aktualisieren (manuell)
2. Copilot: Marktdaten + Auswertung
3. Daily Notes abschließen
4. Alles speichern (iCloud)
→ 30 Minuten
```
