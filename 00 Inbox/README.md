# 📥 00 Inbox – Anleitung

Dein **Sammelbecken** für alles Neue, Ungefilterte und Unkategorisierte.

## 🎯 Zweck

**Inbox = Capture First, Organize Later**

Keine Zeit zum Nachdenken, wo etwas hin gehört? Alles hier ablegen!
- Interessante Stellenanzeige? → Inbox
- Neue Kundenidee? → Inbox
- Link zum Gefahrstoffgesetz? → Inbox
- Spontaner Gedanke? → Inbox

## 📝 So funktioniert's

### 1. Neuen Eintrag erfassen
Erstelle einfach eine neue Markdown-Datei (z.B. `Neue-Bewerbung-Idea.md`)
- Keine Vorlage nötig
- Keine Ordnerstruktur nötig
- Nur: **Schnell festhalten**

### 2. Regelmäßig aufräumen (täglich/wöchentlich)
Jede Notiz hier **wandert nach**:
- **01 Projects/** – wenn es ein konkretes Projekt ist
- **02 Areas/** – wenn es ein Lebensbereich ist
- **03 Resources/** – wenn es Referenzmaterial ist
- 🗑️ **Löschen** – wenn es nicht mehr relevant ist

### 3. Inbox bleibt leer
Das Ziel: Diese Inbox sollte immer **maximal 3-5 Dateien** haben
(außer Willkommen.md, das bleibt)

## 💡 BEISPIELE

### ✅ RICHTIG – Kurz & Ungefiltert
```markdown
# Stellenanzeige Fachkraft Arbeitssicherheit

Montabaur, Klinikum
https://karriere.kk-km.de/...
Deadline: ca. 31.07.2026

→ Später: Nach 01 Projects/Bewerbungen/Firmen/ verschieben
```

### ✅ RICHTIG – Spontan & Chaotisch
```markdown
# Kundenidee: Metallbau Weber

Bruder kennt jemanden
Keine Info noch

→ Später: Nach 01 Projects/Freelance/.../Kunden/ verschieben
```

### ✅ RICHTIG – Link & Notiz
```markdown
# TRGS 519 Update 2026

https://www.baua.de/...
Neue Anforderungen zu Asbest

→ Später: Nach 03 Resources/ verschieben
```

## ⚙️ WORKFLOW

```
1. Neuen Eintrag erstellen
   ↓
2. Notiz in Inbox ablegen
   ↓
3. (Täglich oder wöchentlich)
   Inbox durchgehen
   ↓
4. Jede Notiz:
   [Projekt?] → 01 Projects/
   [Bereich?] → 02 Areas/
   [Ressource?] → 03 Resources/
   [Obsolet?] → Löschen
   ↓
5. Inbox leer (nur Willkommen.md)
```

## 📌 REGELN

**DO:**
- ✅ Schnell Notes erfassen
- ✅ Keine Vorlage nötig
- ✅ Unstrukturiert is OK
- ✅ Links kopieren ist OK

**DON'T:**
- ❌ Inbox als "To-Do Tracker" nutzen
- ❌ Alte Notizen hier liegen lassen (>1 Woche)
- ❌ Wichtige Dateien nicht organisieren
- ❌ "Mal schaue ich später" → führt zu Chaos
