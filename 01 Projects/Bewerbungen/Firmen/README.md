# 🏢 Firmen-Ordner – Anleitung

Jede Bewerbung bekommt hier eine eigene Datei, benannt nach der Firma.

## 📝 Neue Bewerbung erstellen

1. **Kopiere die Vorlage:**
   - `05 Templates/Bewerbung-Template.md`

2. **Benenne die Datei:**
   - Format: `Firmenname.md`
   - Beispiele: `Müller GmbH.md`, `Siemens.md`, `Daimler-Benz.md`

3. **Speichere sie hier:**
   - `01 Projects/Bewerbungen/Firmen/[Firmenname].md`

4. **Fülle die Felder aus:**
   - Firma
   - Position
   - Status (Recherche / Anschreiben in Arbeit / Versendet / Rückmeldung / Interview / Absage / Zusage)
   - Anschreiben-Link
   - Deadline
   - Verlauf / Notizen

## 📋 Status-Optionen

```
Status-Workflow:
Recherche
  ↓
Anschreiben in Arbeit
  ↓
Versendet
  ↓
Rückmeldung erhalten
  ↓
Vorstellungsgespräch
  ├→ Zusage
  └→ Absage

Oder direkt: Absage (wenn nicht interessant)
```

## 🔍 Beispiel-Eintrag

```markdown
---
firma: Müller GmbH
position: Office Manager
status: Versendet
anschreiben-link: [[Link zum Anschreiben]]
deadline: 2026-07-31
tags: [bewerbung]
---

# Bewerbung – Müller GmbH

## Firma
Müller GmbH, Montabaur

## Position
Office Manager mit Gefahrstoff-Fokus

## Status
Bewerbung versendet am 2026-07-05

## Verlauf
- 2026-07-02: Stellenanzeige gefunden bei StepStone
- 2026-07-04: Anschreiben verfasst
- 2026-07-05: Bewerbung versendet per E-Mail
```

## 📌 Tipps

- **Link zum Anschreiben:** Wenn du einen separaten Lebenslauf/Anschreiben hast, verlinke ihn hier
- **Deadline nicht vergessen:** Für Follow-up wichtig
- **Notizen aktuell halten:** Bei Rückmeldungen sofort updaten
- **Abgeschlossene Bewerbungen:** Nach Abschluss → `04 Archive/Bewerbungen/Firmen/`
