# 🤝 Kunden-Ordner – Anleitung

Jeder (potenzielle) Gefahrstoff-Kunde bekommt hier eine eigene Datei für Tracking & Dokumentation.

## 📝 Neuen Kunden erstellen

1. **Kopiere die Vorlage:**
   - `05 Templates/Gefahrstoff-Kunde-Template.md`

2. **Benenne die Datei:**
   - Format: `Kundenname.md`
   - Beispiele: `Müller Metallbau.md`, `ChemTech GmbH.md`, `Dachdeckerei Weber.md`

3. **Speichere sie hier:**
   - `01 Projects/Freelance Gefahrstoffe Aufbau/Kunden/[Kundenname].md`

4. **Fülle die Felder aus:**
   - Kunde (Firmenname)
   - Branche (z.B. Metallverarbeitung, Chemie, Transport)
   - Leistung (Gefahrstoffkataster / Betriebsanweisungen / Unterweisungen / Beratung)
   - Status (Erstkontakt / Angebot erstellt / Beauftragt / In Umsetzung / Abgeschlossen)
   - Nächster Kontakt (Datum für Follow-up)
   - Notizen

## 🎯 Status-Workflow

```
Erstkontakt (Initiierung)
  ↓
Angebot erstellt (Kalkulation & Proposal)
  ↓
Beauftragt (Vertrag unterschrieben)
  ↓
In Umsetzung (Arbeit läuft)
  ↓
Abgeschlossen (Leistung erbracht, Rechnung gestellt)

Oder: Abgelehnt (Kunde interessiert sich nicht)
```

## 💰 Leistungen (Checkboxen)

```
- [ ] Gefahrstoffkataster (Erfassung & Verwaltung)
- [ ] Betriebsanweisungen (Erstellung pro Tätigkeit)
- [ ] Unterweisungen (Schulung der Mitarbeiter)
- [ ] Beratung (allgemeine Gefahrstoff-Beratung)
```

## 📌 Tipps

- **Nächster Kontakt:** Für Follow-ups & Terminerinnerung
- **Branche:** Wichtig für später (Fallstudien, Netzwerk)
- **Leistungen:** Track welche Services pro Kunde erbracht
- **Notizen:** Ansprechpartner, Telefon, Besonderheiten
- **Preis:** Optional in Notizen (z.B. "Angebot: €850")
- **Abgeschlossene Kunden:** Nach Completion → `04 Archive/Freelance/Kunden/`

## 🎯 Ziel

Systematisches Tracking aller Kundenbeziehungen:
- Wer ist interessiert?
- Welche Services?
- Wann ist Folgekontakt fällig?
- Welche sind aktiv / abgeschlossen?
