# 📅 06 Daily Notes – Anleitung

Dein **persönliches Tagebuch** – eine Notiz pro Tag, für Planung, Reflexion & Tracking.

## 🎯 Zweck

Daily Notes sind:
- **Persönlich** (deine täglichen Gedanken & Fortschritt)
- **Chronologisch** (einen pro Tag, Dateiname: `YYYY-MM-DD.md`)
- **Reflektiv** (Morgens planen, abends bilanzieren)
- **Niedrigschwellig** (nicht strukturiert wie Projekte, mehr frei)

## 📝 STRUKTUR EINER DAILY NOTE

Nutze die Template: `05 Templates/Daily-Note-Template.md`

```markdown
---
date: [DATUM]
tags: [daily]
---

# Tagebuch – [DATUM]

## 📋 Prioritäten heute

1. [Priorität 1]
2. [Priorität 2]
3. [Priorität 3]

## 📝 Tagebuch-Notizen

### Morgen
- [Uhrzeit] – [Notiz]
- [Aktivität]
- [Beobachtung]

### Mittag
- [Aktivität durchgeführt]
- [Ereignis/Kommunikation]
- [Ergebnis/Output]

### Abend
- [Reflexion über heute]
- [Offene Punkte für morgen]

## ✅ Heute erledigt

- [x] [Aufgabe 1]
- [x] [Aufgabe 2]
- [x] [Aufgabe 3]

## ❓ Offene Fragen / Punkte

- [Offene Frage 1]
- [Offene Frage 2]
- [Offene Frage 3]

## 🎯 Morgen planen

- [Geplante Aktivität 1]
- [Geplante Aktivität 2]
- [Geplante Aktivität 3]

## 🔗 Verknüpfungen zu heute

- [[02 Areas/[Area-Name]]] — [Bezug]
- [[01 Projects/[Projekt-Name]]] — [Bezug]
- [[03 Resources/[Ressource-Name]]] — [Bezug]
```

## ⚙️ WORKFLOW

### Morgens (Planung)
```
1. Neue Daily Note erstellen (05 Templates/Daily-Note-Template.md)
2. "Prioritäten heute" ausfüllen (max. 3 Dinge!)
3. Offene Punkte überprüfen
4. Ready für den Tag!
```

### Tagsüber (Notizerstellung)
```
1. Spontane Gedanken hinzufügen
2. Wichtige Events/Anrufe protokollieren
3. Projekte updaten wenn etwas Großes passiert
```

### Abends (Reflexion)
```
1. "Heute erledigt" abhaken
2. Offene Fragen/Punkte für morgen notieren
3. "Morgen planen" ausfüllen
4. Verknüpfungen zu Projekten/Areas hinzufügen
```

## 🔗 VERKNÜPFUNGEN

**Deine Daily Notes sollten verlinken zu:**
- Bewerbungen (`01 Projects/Bewerbungen/Firmen/`)
- Kundenprojekte (`01 Projects/Freelance/Kunden/`)
- Learnings (zu `02 Areas/`)
- Recherchen (zu `03 Resources/`)

**Beispiel:**
```markdown
Heute geklärt:
- [[02 Areas/Gefahrstoffe Wissen.md]] — TRGS 519 gelesen
- [[03 Resources/Steuer & Recht/Pricing.md]] — Tarifformel überprüft
```


## 📌 REGELN

**DO:**
- ✅ Täglich eine Notiz (idealerweise)
- ✅ Kurz halten (5-15 Min am Morgen/Abend)
- ✅ Verlinken zu Projekten/Areas
- ✅ Persönlich & reflektiv sein

**DON'T:**
- ❌ Perfektionismus (nicht alles muss strukturiert sein)
- ❌ Super lange schreiben (Tagebuch, keine Essays)
- ❌ Old Daily Notes löschen (Archivieren statt löschen)
- ❌ Projekt-Details hier statt in `01 Projects/`

## 🚀 AUTOMATION – DAILY NOTES PLUGIN

**Empfohlene Setup (Obsidian Core Plugin):**

1. Öffne **Settings → Core Plugins → Daily Notes**
2. Aktiviere: ✅ Daily Notes
3. Konfiguriere:
   - **Folder:** `06 Daily Notes`
   - **Template file:** `05 Templates/Daily-Note-Template.md`
   - **Date format:** `YYYY-MM-DD`
4. Jetzt: Klick auf **"Daily Note"** (oben rechts) → Heute's Notiz automatisch erstellt!

**Tastenkombination:** (je nach System)
- Mac: `Cmd + Shift + D`
- Windows: `Ctrl + Shift + D`


## 🎯 MAINTENANCE

| Aufgabe | Häufigkeit | Notizen |
|---------|------------|---------|
| Neue Daily Note | Täglich | Am Morgen oder Abend |
| Alte Notes archivieren | Monatlich | >30 Tage alt → 06 Daily Notes/Archive/ |
| Wochenrückblick | Wöchentlich | Freitag Abend |
| Monatsrückblick | Monatlich | Am 5. des nächsten Monats |
| Learnings konsolidieren | Monatlich | → zu `02 Areas/` oder `03 Resources/` |

## 📈 NUTZEN

**Daily Notes sind wertvoll für:**
- 📊 Fortschritts-Tracking (wann was getan)
- 🎯 Gewohnheits-Building (täglich reflektieren)
- 🧠 Gedächtnistsütze (was war wann?)
- 🔄 Feedback-Loops (morgens planen, abends reflektieren)
- 📝 Content für spätere Schreiben (z.B. Bewerbungs-Anschreiben)
